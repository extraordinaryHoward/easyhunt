# Easyhunt P1、P2 改造结果（2026-10-17）

对照《Easyhunt 参考产品功能差距与改造清单-2026-10-16.md》实施。本轮代码能力和集成测试不等于已经通过真实 BOSS 账号验收。

| 项目 | 已实现 | 验证边界 |
| --- | --- | --- |
| P1 平台设置 | BOSS 职位绑定、搜索词增删改与拖动排序、场景顺序、城市、执行预览；多搜索词依序进入单个可取消的 operation，按候选人引用去重 | 只有已接线的搜索词和城市会执行。公司、推荐/投递/复聊及扩展筛选显示待验证，不会伪装成已支持 |
| P1 人才画像 | 保存版本、查看与切换当前版本；本地简历分析记录评分时的画像版本 ID，旧结果保留 | 切换版本不会自动重评；历史无版本 ID 的分析显示“未记录” |
| P1 浏览器 | 独立窗口和小窗复用/销毁后重建；登录跳转、离开 BOSS 页的状态提示；桥接会话可重置 | 真实账号的窗口往返与 BOSS 登录状态仍需人工验收 |
| P1 分享 | 分享前预览文字、指定协作人或全部登录用户、READ/EDIT 权限、一个月有效期；服务端过期返回 410，列表不再显示；原始 PDF 不上传 | 本地免登录模式禁用云端分享；云模式需要配置加密密钥 |
| P1 系统设置 | 重启新手引导、撤销平台授权并停止任务、清除 BOSS 浏览器会话；迁移存储目录时逐文件比对 SHA-256 | 目录迁移需先自行复制完整旧数据；清除浏览器数据保留工作台本地状态 |
| P2 寻访 Skill | 可复制的本机 Agent 接入说明、最近 100 条 operation 回执 | 本机服务须保持运行，平台任务仍须签署授权 |
| P2 账户与平台能力 | 云模式读取真实积分与邀请码，本地模式显示未连接；猎聘/智联等未验证 Skill 保持禁用 | 不显示虚构余额，也不开放未验证平台自动化 |

## 验证

在仓库根目录运行 `npm run build`、`npm test`。Playwright 的 Chromium 用例需要允许浏览器进程启动的本机环境。macOS 安装 ZIP：`desktop/release/Easyhunt-0.8.0-arm64-mac.zip`。

## 后续真实账号验收

在已签署授权的 BOSS 账号中检查登录跳转、职位同步后绑定、多个搜索词依序采集、窗口反复开关、人工接管，以及退出/清除会话后的状态。当前没有对真实账号执行这些动作。
