## 验证

在仓库根目录运行 `npm run build`、`npm test`。Playwright 的 Chromium 用例需要允许浏览器进程启动的本机环境。macOS 安装 ZIP：`desktop/release/Easyhunt-0.8.1-arm64-mac.zip`。

## 复核修复（0.8.1）

- 平台配置预览与实际 `boss.collect` 请求共用搜索词去重、职位引用和数量校验；失效职位绑定会阻止启动。搜索词增加指定位置插入。
- 云端账户菜单新增“与我分享”入口；收件人列表会读取真实分享，READ 只读、EDIT 可保存已分享文字；服务端列表返回有效权限。原始 PDF 仍保留本机。
- 简历分析标出所用画像的版本号和保存时间；旧版标记为历史版本，不因切换画像自动重评。
- 浏览器截图失败时返回空预览，平台页面无法证明登录时明确显示“登录状态待确认”；清理会话时覆盖当前 BOSS 子域。
- 存储迁移拒绝目标目录中的符号链接；账户积分和邀请码独立读取，失败时显示“暂不可用”；任务配置拒绝非整数与空职位名。
- RPA 授权创建必须由桌面桥接进程携带本机密钥。其他本机进程不能仅提交 `signedAgreement: true` 冒充用户签署。

复核后在本机运行 `npm test`：云端 6、RPA 22、前端 12、桌面 1，合计 41 项通过；`npm run build` 通过。真实 BOSS 账号的登录、职位同步与多页采集仍需在用户已授权的账号上现场验收，不能由模拟 DOM 测试替代。

## 后续真实账号验收

在已签署授权的 BOSS 账号中检查登录跳转、职位同步后绑定、多个搜索词依序采集、窗口反复开关、人工接管，以及退出/清除会话后的状态。当前没有对真实账号执行这些动作。
